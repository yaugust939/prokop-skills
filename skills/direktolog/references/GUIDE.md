# GUIDE — Скил `direktolog`: как пользоваться

> Руководство для агента Прокопий и операторов: что делает скил, как его
> вызывать, полный воркфлоу, шаблоны и типовые сценарии использования.

---

## 1. Что это и зачем

`direktolog` — самодостаточный скил директолога: Яндекс.Директ + click.ru.
Позволяет Прокопию **проектировать, запускать, оптимизировать и отчитываться**
по рекламным кампаниям, а также **совершенствовать сам скил** по мере накопления
опыта.

Кто работает:
- **Прокопий** берёт роль директолога сам (если агента Директолог нет);
- либо координирует исполнение агентом Директолог (санкция бюджета, приём отчётов).

## 2. Быстрый старт — как вызвать

Скил активируется фразами-триггерами. Примеры запросов к Прокопию:

| Запрос | Что делает |
|---|---|
| «Настрой рекламу моей стоматологии в ЛО» | Полный цикл: бриф → стратегия → кампания |
| «Посчитай KPI для юриста при бюджете 40 000 ₽/нед» | Расчёт CTR/CPC/CR/CPA/CPL/ДРР |
| «Запусти кампанию для МСП» | Стратегия МСП + шаблон объявлений |
| «Собери семантику по "психолог онлайн"» | Wordstat: ядро 10–16 фраз + минус-слова |
| «Оптимизируй ставки по прошлой неделе» | Еженедельная оптимизация + отчёт |
| «Сделай отчёт по рекламе за неделю» | `templates/report-weekly.md` |
| «Как маркировать рекламу?» | 347-ФЗ, Мастер маркировки click.ru |
| «Обнови бенчмарки в скиле» | Развитие скила (см. §7) |

**Порядок всегда**: пойми задачу → возьми бриф (если нет) → считай → проектируй →
запускай → оптимизируй → отчитывайся. Без брифа не обещай цифры и сроки.

## 4. Полный воркфлоу (8 шагов)

1. **Бриф** → `templates/brief.md`: сфера, гео (ЛО = 10857), ЦА, УТП, цель,
   бюджет, посадочная. Нет брифа — собрать из диалога.
2. **Семантика** → Wordstat API / Парсер click.ru / Key Collector: 10–16 фраз
   (1–2 ВЧ в заголовки, 8–12 СЧ в ключи), минус-слова, UTM.
3. **KPI** → формулы: Клики=Бюджет/CPC; CPA=CPC/CR; ДРР=Расход/Выручка.
   Бенчмарки — таблица в SKILL.md + «Пульс» click.ru.
4. **Стратегия МСП** → `templates/strategy.md` (≤ 2 стр. A4).
5. **Кампания** → Direct API v5 или перенос через click.ru; гео, стратегия ставок.
6. **Объявления** → лимиты 56/30/81, гуманизация YandexGPT, 2+ варианта.
7. **Оптимизация** (еженедельно) → CTR/CPC/CR, ставки, минус-слова, A/B,
   ретаргетинг, защита от скликивания.
8. **Отчёт** → `templates/report-weekly.md`; ежемесячно ДРР/ROAS/ROMI.

Каждый запуск сверять с `templates/checklist-launch.md`.

## 5. Ключевые KPI и пороги эскалации

| KPI | Цель | Порог эскалации |
|---|---|---|
| CTR (поиск) | ≥ 5% | < 3% |
| CPC | ≤ 50 ₽ | > 100 ₽ |
| Конверсия | ≥ 2% | < 1% |
| CPL | ≤ 2 000 ₽ | > плана |
| ДРР / ROAS | в плане | выше плана |

Если метрика за порогом — оптимизировать или эскалировать Маркетологу/Прокопию.

## 6. Сценарии использования

### Сценарий 1. Новый клиент МСП: стратегия с нуля
**Запрос**: «Прокопий, к нам пришла частная клиника в Гатчине (ЛО). Бюджет
60 000 ₽/мес, цель — запись на приём. Сделай стратегию.»

Шаги:
1. Собрать бриф (гео = ЛО id 10857, цель = заявки, ниша = медицина).
2. Семантика: `стоматология гатчина`, `записаться к стоматологу`, `лечение зубов цена`…
   + минус-слова (`бесплатно`, `отзывы`, `вакансия`).
3. KPI по бенчмаркам «Медицина» (ЛО): CTR ~4.0%, CPC ~18 ₽, CR ~5.5%.
   Бюджет 60 000/мес ≈ 13 850 ₽/нед → клики/нед ≈ 770 → заявки/нед ≈ 42 → ~180/мес.
4. Заполнить `templates/strategy.md`, показать клиенту на утверждение.
5. После согласования — запуск по `checklist-launch.md`.

**Результат**: стратегия (≤ 2 стр. A4) + прогноз KPI + план запуска.

### Сценарий 2. Еженедельная оптимизация действующей кампании
**Запрос**: «Прокопий, разбери прошлую неделю по психологу и предложи правки.»

Шаги:
1. Выгрузить факт из Метрики/сквозной аналитики: CTR, CPC, CR, заявки, расход.
2. Сравнить с планом (`report-weekly.md`, колонка Δ).
3. Решения: отключить нецелевые фразы (минус-слова), поднять ставки на конверсионные,
   остановить объявление с CTR < порога, запустить A/B.
4. Оформить `report-weekly.md` и вердикт клиенту.

**Результат**: еженедельный отчёт + список правок + прогноз.

### Сценарий 3. Быстрый расчёт KPI под бюджет
**Запрос**: «Юрист в ЛО, бюджет 40 000 ₽/нед. Что получим?»

Ответ по формулам (ниша B2B/услуги, CPC ~25 ₽, CR ~5%):
- Клики/нед = 40 000 / 25 = 1 600; Заявки/нед = 1 600 × 5% = 80;
- CPA = 500 ₽; Заявки/мес ≈ 346; ДРР — по среднему чеку.
Это «прикидка» до брифа; финальные цифры — после сбора семантики.

### Сценарий 4. Аудит чужого аккаунта (приём клиента)
**Запрос**: «Клиент принёс свой Директ. Что с ним не так?»

Шаги:
1. Запросить доступ (токен в keyring) или выгрузку статистики.
2. Прогнать по чек-листу: структура кампаний, минус-слова, UTM, цели Метрики,
   соответствие объявлений лимитам 56/30/81, маркировка.
3. Дать отчёт «найдено / последствия / фикс» с приоритетами.

### Сценарий 5. Запуск с маркировкой (347-ФЗ)
**Запрос**: «Надо запустить рекламу и не нарушить закон о маркировке.»

Порядок: Мастер маркировки click.ru → получить erid → передать в ОРД → только
потом публиковать. Без erid публикация запрещена (штрафы). Все шаги — в
`checklist-launch.md` (блок «Аналитика и комплаенс»).

### Сценарий 6. A/B тест объявлений + гуманизация
**Запрос**: «Напиши 3 варианта объявления для косметолога и подготовь A/B.»

1. УТП + ключ в Заголовок 1 (≤56), выгода в Заголовок 2 (≤30), текст ≤81 с CTA.
2. Гуманизация через YandexGPT (2 варианта), правка под лимиты.
3. Запустить A/B (2–4 недели), победителя масштабировать, проигравших — выключить.

### Сценарий 7. Расширение: ретаргетинг/ЕПК по результатам
**Запрос**: «Поиск работает, добавь ретаргетинг.»

На базе данных Метрики: сегмент посетителей 7–14 дней → отдельная кампания
ретаргетинга; если e-commerce/товарка — ЕПК или товарные объявления.
Считать отдельно: CPA ретаргетинга обычно ниже поискового.

### Сценарий 8. Отчётность и дистрибуция результата
**Запрос**: «Сформируй отчёт для владельца клиники.»

- Краткий отчёт (владелец бизнеса): расход, заявки, CPA, ДРР — без жаргона.
- Подробный (маркетолог): по кампаниям/фразам, Δ к плану, план следующей недели.
- Готовый PDF — онлайн-отчёт click.ru (логотип, ссылка/файл).

### Сценарий 9. Роутинг: посетитель сайта просит рекламу
**Вход**: человек на сайте Нейро-артели пишет «Хочу запустить рекламу своего
бизнеса». Прокопий (веб-агент) видит триггер → скил `direct-routing` →
уточняет задачу/бюджет/регион → передаёт в директ-контур (сбор брифа).
**Правило**: сначала контекст, потом оффер; без брифа цифр не обещать.

### Сценарий 10. Развитие самого скила
**Запрос**: «Обнови бенчмарки под свежие данные Директа.»

1. Взять актуальные CPC/CTR/CR из «Пульса» click.ru (или из реальных кампаний).
2. `prokop_skills_manage(patch)` таблицы бенчмарков в SKILL.md
   (`old_string` = старая строка, `new_string` = новая).
3. Добавить нишу/минус-слова/кейс: `patch` SKILL.md или `write_file` в references/.
4. Изменить шаблон: `write_file` в `templates/`.
5. Бампнуть `version` в frontmatter (patch) при существенных правках.
6. Записать изменение в `CHANGELOG.md`.

## 7. Как Прокопий совершенствует скил

Нативный механизм навыков (`prokop_skills_manage`):

| Операция | Когда |
|---|---|
| `list` | посмотреть доступные скилы |
| `view` | прочитать SKILL.md / references-файл |
| `patch(old_string, new_string)` | точечная правка (уникальный фрагмент или `replace_all`) |
| `edit(content)` | полная перезапись (целиком новый SKILL.md) |
| `write_file(file_path)` | добавить/заменить файл в `references/ templates/ scripts/ assets/` |
| `remove_file(file_path)` | удалить связанный файл |

Правила:
- Версия бампается только при существенных изменениях; каждый релиз — в CHANGELOG.
- Не дублировать рецептуру в другие скилы (`yandex-direct` остаётся процедурным).
- Рабочая копия = `~/.prokop/skills/direktolog/`; эталон в `D:\OBS_Yandex_Prokopii`
  синкается по договорённости (осознанный перенос после проверки).

## 8. Типовые ошибки и как их избегать

| Ошибка | Как избежать |
|---|---|
| Запуск без брифа | Шаг 1 обязателен; без УТП/гео/бюджета не считать KPI |
| Нет минус-слов / UTM | Чек-лист запуска, п. «Подготовка» |
| Объявление с CAPS/сокращениями | Лимиты 56/30/81 + запрещённый список в SKILL.md |
| Запуск без маркировки | erid до публикации; п. «Аналитика и комплаенс» |
| Превышение бюджета | Только с санкции Прокопия/Маркетолога |
| Токены в тексте/логах | Всё в keyring/env |
| Прогноз без «Пульса» | Бенчмарки сверять с актуальными данными click.ru |
| Устаревшие данные в скиле | Регулярно бампить бенчмарки по сценарию 10 |

## 9. Глоссарий

- **СЯ** — семантическое ядро (ключевые фразы).
- **ВЧ/СЧ/НЧ** — высоко/средне/низкочастотные запросы.
- **CTR** — кликабельность (клики/показы). **CPC** — цена клика.
- **CR** — конверсия (целевые/клики). **CPA** — цена целевого действия.
- **CPL** — цена лида. **ДРР** — доля рекламных расходов.
- **ROAS/ROMI** — окупаемость рекламы (выручка/расход; маржа/расход).
- **РСЯ** — Рекламная сеть Яндекса. **ЕПК** — Единая перфоманс-кампания.
- **ЛО** — Ленинградская область (гео-id 10857).
- **UTM** — метки ссылок для аналитики. **347-ФЗ** — закон о маркировке рекламы.
- **ОРД** — оператор рекламных данных. **erid** — идентификатор рекламы.
