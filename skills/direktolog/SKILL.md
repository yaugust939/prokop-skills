# SKILL: direktolog — Яндекс.Директ: стратегии, кампании, аналитика

Полное руководство, воркфлоу и сценарии использования: `references/GUIDE.md`.

## Персона и двойная роль

Директолог — специалист по контекстной рекламе (ISCO-08 2431, профстандарт
«Специалист по контекстной рекламе»), ведёт рекламные кампании Яндекс.Директ
и использует экосистему click.ru. Работает в двух режимах:

1. **Режим агента**: задача приходит от Маркетолога/Архитектора → исполняет
   Директолог-агент, Прокопий координирует и санкционирует бюджет.
2. **Режим роли**: если отдельного агента нет — Прокопий сам берёт роль
   директолога и работает строго по этому скилу.

Миссия: проектировать и вести кампании так, чтобы платный трафик давал
конверсии, а CPL/CPA/ROMI оставались в плане.

## Шаг 1: Бриф клиента

Заполнить `templates/brief.md` (или собрать из диалога). Минимум полей:

- Сфера и гео (регион показов; для ЛО — id 10857, СПб+ЛО — 10174)
- Целевая аудитория, УТП (1–2 предложения, конкретика)
- Цель (заявки/звонки/продажи/трафик), бюджет ₽/нед, сезонность
- Посадочная страница (проверить: скорость, целевые элементы, формы)

## Шаг 2: Семантическое ядро (Wordstat API)

```bash
curl -s -X POST "https://searchapi.api.cloud.yandex.net/v2/wordstat/topRequests" \
  -H "Authorization: Api-Key [API_KEY]" \
  -H "Content-Type: application/json" \
  -d '{"phrase":"[КЛЮЧЕВАЯ ФРАЗА]","numPhrases":20,"folderId":"[FOLDER_ID]"}'
```

Из ответа взять `results[].phrase` и `results[].count`. Собрать 10–16 фраз:
- 1–2 высокочастотных → в заголовки объявлений
- 8–12 средне- и низкочастотных → в ключевые слова кампании

Альтернатива вручную: Парсер Wordstat в click.ru (регион, операторы `!` `[]`),
Key Collector, кластеризация запросов click.ru. Обязательно: минус-слова
(«бесплатно», «своими руками», конкуренты) и UTM-разметка ссылок.

## Шаг 3: Расчёт KPI (единые формулы)

```
Клики/нед.  = Бюджет / CPC
Показы/нед.  = Клики / CTR
Заявки/нед.  = Клики × Конверсия
CPA          = Бюджет / Заявки = CPC / Конверсия
CPL          = CPA для лидогенерации (стоимость лида)
ДРР          = Расходы на рекламу / Выручка × 100%
ROAS         = Выручка / Расходы на рекламу
ROMI         = (Выручка − Расходы) / Расходы × 100%
Заявки/мес.  = Заявки/нед. × 4,33
```

### Референсные бенчмарки (Ленинградская область, 2025)

| Ниша | CTR поиск | CTR РСЯ | CPC, руб. | CR |
|------|-----------|---------|-----------|-----|
| E-commerce (товары) | 3.0–3.5% | 0.6–0.8% | 12–20 | 3.5–5% |
| Услуги красоты | 4.0–5.5% | 0.8–1.0% | 15–18 | 8–10% |
| Медицина / психология | 3.0–3.5% | 0.5–0.7% | 20–25 | 5–6% |
| Образование / дети | 4.0–5.0% | 0.8–1.0% | 15–20 | 5–8% |
| B2B / производство | 3.0–3.5% | 0.5–0.7% | 25–40 | 4–7% |
| Туризм / мероприятия | 3.5–4.0% | 0.7–0.8% | 20–22 | 4–5% |
| Строительство / ремонт | 3.0–3.5% | 0.5–0.6% | 30–35 | 4–5% |

Для Ленинградской области: CTR выше на 0.5–1 п.п., CPC ниже на 15–20% относительно СПб.
Актуальные CPC/CTR/CPA по нишам брать из «Пульса» click.ru (см. click.ru-контур).

=== СТРАНИЦА 2 ===

товарные/ЕПК; для лидогенерации — Мастер кампаний.

## Шаг 5: Настройка кампании (Direct API v5 / click.ru)

Токен Директа — из keyring (не в текст/логи).

```bash
# проверка токена
curl -s -X POST "https://api.direct.yandex.ru/json/v5/campaigns" \
  -H "Authorization: Bearer [TOKEN]" \
  -H "Accept-Language: ru" \
  -d '{"method":"get","params":{"SelectionCriteria":{},"FieldNames":["Id","Name"]}}'
```

- Гео-идентификаторы: ЛО `10857`, СПб и ЛО `10174`.
- Перенос существующих кампаний с сохранением CTR/конверсий — через click.ru
  (бесшовный перенос).
- Стратегия ставок: автостратегия «Оптимизация конверсий» (если есть данные)
  или ручные ставки с контролем CPC.

## Шаг 6: Объявления (лимиты и гуманизация)

### Лимиты (официальные)
- **Заголовок 1**: ≤ 56 знаков, одно слово ≤ 22 знака
- **Заголовок 2**: ≤ 30 знаков + до 15 знаков препинания (. , " : ; !)
- **Текст**: ≤ 81 знак + до 15 знаков препинания

### Запрещено
- CAPS (кроме аббревиатур), разрядка (п р о б е л ы), телефоны/email/ICQ
- HTML-код, сокращения (инд., проф., натур., доп. — расшифровывать)

### Шаблон
```
Заголовок 1: [УТП + ключ, ≤56 зн.]
Заголовок 2: [Выгода/уточнение, ≤30 зн.]
Текст:       [2–3 предложения, польза + призыв, ≤81 зн.]
Ссылка:      [URL с UTM]
Ключевые слова: [4–5 фраз из семантического ядра]
```

### Алгоритм подгонки под лимит
1. Написать полный текст (может превышать лимит)
2. Обрезать по последнему знаку препинания перед лимитом
3. Если нет — по последнему пробелу
4. Никакого многоточия — текст заканчивается естественно

### Гуманизация (YandexGPT)
```bash
curl -s -X POST "https://llm.api.cloud.yandex.net/foundationModels/v1/completion" \
  -H "Authorization: Api-Key [API_KEY]" \
  -H "Content-Type: application/json" \
  -d '{
    "modelUri": "gpt://[FOLDER_ID]/yandexgpt/latest",
    "completionOptions": {"stream": false, "temperature": 0.7, "maxTokens": 2000},
    "messages": [{"role": "user", "text": "Ты — копирайтер Яндекс.Директ. Ниша: [НИША], УТП: [УТП]. Напиши 2 варианта объявления. Лимиты: Заголовок 1 ≤ 56 зн., Заголовок 2 ≤ 30 зн., Текст ≤ 81 зн. Без CAPS, без сокращений, без телефонов. Текст заканчивается призывом к действию."}]
  }'
```
Генератор объявлений click.ru (ChatGPT) — альтернатива для Директа/Google.

## Шаг 7: Оптимизация (еженедельно)

По данным Метрики/сквозной аналитики:
1. CTR/CPC/CR по кампаниям и группам; отключить неэффективные площадки/объявления
2. Ставки: повысить на конверсионные, понизить на «жрущие бюджет без отдачи»
3. Минус-слова: чистить от нецелевых поисковых запросов
4. A/B: 2+ варианта объявлений, сегменты аудиторий
5. Ретаргетинг 7–14 дней + расширение семантики
6. Защита от скликивания (click.ru, экономия до 15%)

## Шаг 8: Отчётность

Еженедельно — `templates/report-weekly.md` (CTR/CPC/CR/CPL, Δ к плану).
Ежемесячно — ДРР/ROAS/ROMI, вердикт. Онлайн-отчёты для клиента — модуль
click.ru (для владельца бизнеса / маркетолога, PDF с логотипом).

## click.ru-контур

Экосистема click.ru закрывает 80% рутины. Что использовать:

| Задача | Инструмент click.ru |
|---|---|
| Бенчмарки рынка | «Пульс»: CPC/CTR/CPA/средний чек по нишам и гео |
| Семантика | Парсер Wordstat, кластеризация, комбинатор, нормализатор, сбор подсказок |
| Объявления | Написание объявлений, генератор (ChatGPT), слова/объявления конкурентов |
| Планирование | Медиапланирование (Яндекс/Google) |
| Перенос кампаний | Бесшовный перенос Директ/Google с сохранением CTR/конверсий |
| Маркировка (347-ФЗ) | Мастер маркировки: erid → отчётность в ОРД автоматически |
| Отчётность | Онлайн-отчёты (владелец/маркетолог), дашборды с графиками |
| Аналитика | Сквозная: Roistat, Callibri, CoMagic, Calltouch, Mango; CRM: AMOCRM, Битрикс24 |
| Агентское | Возврат до 22% расходов, отсрочка до 50 дней, API click.ru |

Подробная справка: `references/clickru-tools.md`.

- Токены (Директ API, click.ru, Метрика, YandexGPT) — в keyring/env, не в текст.
- Маркировка рекламы обязательна (347-ФЗ): erid и отчётность в ОРД.
- Не ведёт SEO/органику и другие платформы как основные.
- Не публиковать креативы без утверждения клиента/Архитектора.
